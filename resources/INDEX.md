# Resource Index

Every resource, split by whether it's been studied yet. A resource moves between sections —
cut the row from one table and paste it into the next, never duplicate it.

**Adding to the queue is deliberately low-friction.** Title and link are enough. Fill in the
rest when you get to it. The point is that hearing about something and capturing it should
take ten seconds, so nothing gets lost.

Trust is only assessed *after* reading, so it lives in the Studied table.
