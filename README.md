# media_biz_research

Research into how media businesses — newsletters, YouTube channels, podcasts, short-form
social — get built, monetized, and sustained, and how to turn that into a niche pick and an
execution strategy.

Start with [PROJECT.md](PROJECT.md) for goals and scope, [DECISIONS.md](DECISIONS.md) for
choices made so far, and [LEARNINGS.md](LEARNINGS.md) for the distilled findings.
[CLAUDE.md](CLAUDE.md) documents the file structure and working conventions.
